# OMNI Contact Center

Веб-интерфейс Контакт-центра OMNI для `https://cc.clz.ru`.

## Окружение

- AlmaLinux 9.8
- nginx на портах 80/443 с перенаправлением HTTP на HTTPS
- Apache + PHP 8.5 (`mod_php`)
- MariaDB 10.11
- каталог приложения: `/var/www/omniweb`

## Структура

Публичные файлы приложения находятся в каталоге `site/`.

Пользователи и их хеши паролей синхронизируются из внутреннего OMNI. Браузер сотрудника
никогда не перенаправляется на `omni.clz.ru`: вход и сессия работают локально на КЦ.

## Проверка

```bash
find site tests -name '*.php' -print0 | xargs -0 -n1 php -l
php tests/card_refund_static_test.php
php tests/datareon_shops_test.php
```

## Возвраты подарочных сертификатов

Страница `site/card_refund.php` принимает XLSX, проверяет обязательные поля и сохраняет
обращения в локальную очередь. Сам файл не сохраняется, а содержимое обращений хранится
в MariaDB только в зашифрованном виде (AES-256-GCM). Внутренний OMNI по HTTPS забирает
очередь через `site/bridge_api.php` и подтверждает импорт. После подтверждения зашифрованная
полезная нагрузка очищается из очереди КЦ.

Ожидаемые колонки XLSX: номер карты, дата обращения, номер обращения, телефон
`7XXXXXXXXXX`, электронная почта, ФИО на кириллице, БИК из 10 цифр и расчётный счёт
из 20 цифр. Неверные необязательные значения очищаются с замечанием по строке;
строка отклоняется только при неверном номере карты.

Для проверки баланса КЦ обращается непосредственно к `api.mindbox.ru`.
Настройки четырёх брендов передаются из OMNI в КЦ через подписанный HTTPS bridge
и хранятся в базе КЦ с шифрованием ключей. Проверка организации обращается с КЦ
напрямую к production Datareon. Пользователи и забор возвратов также
синхронизируются по направлению OMNI → КЦ. Магазины Datareon поступают на КЦ
через `POST /datareon_shops.php`; OMNI читает их через подписанный bridge.
Конфигурация хранится вне web-root:

- `/etc/omniweb/database.php` — подключение к MariaDB;
- `/etc/omniweb/bridge.php` — общий секрет API и отдельный локальный ключ шифрования очереди.

Примеры находятся в `deploy/`. Для проверки Mindbox нужна таблица
`database/migrate_cc_mindbox_settings.sql`; команды выполнения через действующий PDO
сервера КЦ приведены в `deploy/card-tools.md`.

## Выкладка

Выкладка выполняется вручную внутри закрытого офисного контура после получения
изменений из согласованной ветки. Автоматического деплоя из GitHub нет.
Команды для этой функции: [`deploy/card-tools.md`](deploy/card-tools.md).
Описание приёма магазинов: [`deploy/datareon-shops.md`](deploy/datareon-shops.md).
