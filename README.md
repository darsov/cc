# OMNI Contact Center

Веб-интерфейс Контакт-центра OMNI для `https://cc.clz.ru`.

## Окружение

- AlmaLinux 9.8
- nginx на портах 80/443 с перенаправлением HTTP на HTTPS
- Apache + PHP 8.5 (`mod_php`)
- MariaDB 10.11
- каталог приложения: `/var/www/omniweb`

## Структура

Публичные файлы приложения находятся в каталоге `site/`.

Пользователи и их хеши паролей синхронизируются из внутреннего OMNI. Браузер сотрудника
никогда не перенаправляется на `omni.clz.ru`: вход и сессия работают локально на КЦ.

## Проверка

```bash
find site tests -name '*.php' -print0 | xargs -0 -n1 php -l
php tests/card_refund_static_test.php
```

## Возвраты подарочных сертификатов

Страница `site/card_refund.php` принимает XLSX, проверяет обязательные поля и сохраняет
обращения в локальную очередь. Сам файл не сохраняется, а содержимое обращений хранится
в MariaDB только в зашифрованном виде (AES-256-GCM). Внутренний OMNI по HTTPS забирает
очередь через `site/bridge_api.php` и подтверждает импорт. После подтверждения зашифрованная
полезная нагрузка очищается из очереди КЦ.

КЦ не открывает соединения во внутренний OMNI. Все интеграционные запросы идут только
из OMNI в КЦ и подписываются HMAC. Конфигурация хранится вне web-root:

- `/etc/omniweb/database.php` — подключение к MariaDB;
- `/etc/omniweb/bridge.php` — общий секрет API и отдельный локальный ключ шифрования очереди.

Примеры находятся в `deploy/`. Схема БД создаётся администратором вручную из
`database/migrate_cc_portal.sql`.

## Выкладка

Выкладка выполняется вручную внутри закрытого офисного контура после получения
изменений из ветки `main`. Автоматического деплоя из GitHub нет.
